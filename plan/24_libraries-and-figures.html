Real Libraries in Stage B + Figures from Real Data

Built 2026-06-10 · 126 tests green · experiments can install deps + plot; the paper embeds the real figures

Two linked gaps: Stage-B code was effectively stdlib-only (the sandbox runs --network none, so no pip install), and the paper's figure was a single bar chart synthesized host-side from the scalar metric — not a real plot of the experiment's data. Fixed both.

1 · Libraries — declare-deps install phase

The coder now returns a requirements list alongside the code. The sandbox runs in two phases so untrusted code still never touches the network:

PREP (network ON):  pip install --target /site <requirements>   ← in a throwaway container
RUN  (--network none): python experiment.py  with PYTHONPATH=/site (mounted read-only)
  • Real libraries, isolated execution. Install has network; the experiment does not.
  • If pip install fails (bad/typo'd package), it surfaces as the run failure → the council sees it and fixes/drops the dep on the next iteration (existing feedback loop).
  • mise run build-image still pre-bakes numpy/pandas/scipy/sklearn/matplotlib so common deps are instant; declared requirements install on top.
  • Caveat: the install step pip-installs LLM-chosen packages (supply-chain surface). It runs inside the throwaway container, not on the host; pin/allowlist is a future hardening.

2 · Figures — Stage B plots, Stage C embeds

Stage B: experiment.py saves plots → figures/*.png   (from its REAL computed data)
         → collected by the sandbox → projects/<id>/experiment/<rq>/figures/
Stage C: copies them into paper/assets/ (prefixed by RQ) → embeds in paper.md + LaTeX
         (\includegraphics) and the writer references them in Results
fallback: if the experiment produced no figure, Stage C synthesizes one bar chart host-side
  • The sandbox collects *.png/pdf/svg (top-level or figures/) back as bytes; Stage B writes them under each RQ; Stage C copies + references them.
  • Figures are real plots of the experiment's data, not a host-side approximation — matching how research figures are actually produced.
