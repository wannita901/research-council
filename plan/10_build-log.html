LLM-wiki librarian — complete (schema · router · ingest · harvest · lint) 2026-06-07 · 64 tests green

Spec re-grounded in 16; started the write side (the librarian). First two modules of research_council/librarian/:

  • schema.py — WikiPage (typed page + YAML frontmatter: type · title · origin · papers · related · updated) with render_page/parse_page round-trip, slugify, wiki_path, and a Source model (ingest unit; text treated as data). The origin field is the contamination guard — external = prior art, internal = council synthesis (invalid coerces to external; type must be one of the 9 folders).
  • router.py — Librarian: one Sonnet pass (PydanticAI, output_type=RoutingResult) that turns a Source into typed, cross-linked WikiPages. The 4-way disambiguation (approaches=built · methods=validated · concepts=idea · motivations=why) is in the system prompt; malformed routes dropped, origin/papers/updated stamped; usage costed via UsageMeter. Pure — returns pages; persistence is ingest.py.
  • ingest.py — Ingestor: route a Source → cross-link the papers/ anchor to its fan-out → write/merge typed pages (atomic per-file, no git commit) → regenerate index.md from the tree → append log.md. Existing pages compound (union papers/related, append the new source's section under a provenance marker); a page touched by any external source escalates to origin: external. External sources also save an immutable copy to raw/external/; internal (council) writes only wiki/.
  • council ingest <file> wired — reads a local source, builds the Sonnet librarian from wiki.yaml, ingests, prints pages touched + cost. (Needs an Anthropic key via mise.)
  • harvest.py — opt-in, post-run: the wiki compounds from each ideation run. Internal = the council's synthesis (selected idea + surfaced gaps + key critiques) → one origin:internal source the librarian routes into findings/gaps/concepts (Karpathy "file good answers back"). External = the real papers the council cited (brief.refs) whose metadata is in the retrieval cache → origin:external sources, deduped and capped (8/run) to bound cost. Wired into ideate as a typer.confirm prompt (live + interactive only) that shows the call count before spending tokens; failures never sink a finished run. Added CachedRetrieval.cached_papers() as the run's source pool.
  • lint.py — council lint. Structural checks are pure/offline: broken cross-links, orphans (a non-anchor page nothing links to; papers/ anchors exempt), index drift (entries vs files), empty pages — plus an opt-in --semantic LLM pass that flags cross-page contradictions and surfaces gaps over the findings/gaps/concepts corpus. Each run appends to log.md.
  • Docs/layout — knowledge/CLAUDE.md updated: rc→council; the origin: contamination guard (external = prior art, internal = filed-back synthesis, escalation rule); auto-merge + log audit (no git commit). raw/internal/ retired.

Live-run fixes — iterate, fair scoring, librarian progress + trace, aesthetics 2026-06-07 · 70 tests green

  • Rounds redesigned — --rounds was vestigial: non-interactive always auto-concluded at round 1, and interactively it only cut off iterate (the bug you hit). Removed it. Now rounds are human-driven interactively (iterate/amend until you conclude/select), bounded by a fixed safety ceiling (SAFETY_MAX_ROUNDS = 8) — and the gate hides iterate/amend once the ceiling is reached (no more offering an option that won't run). For unattended runs, the new --auto-iterate N flag (default 1) makes the no-human policy run N rounds then conclude. A capped event fires only at the ceiling.
  • Fairer scoring (was "Cathy always wins") — two biases removed: (1) anonymization now shuffles labels (C1/C2/C3 no longer map to fixed vendor seats → no position leak), and (2) aggregate_v2 drops self-scores (a peer no longer scores its own idea — the self-preference guard alongside blind scoring). The ranking table now shows the per-axis breakdown (novelty/soundness/feasibility/clarity) so the number is transparent.
  • Librarian progress + trace — harvest shows a live rich progress bar (per source); council ingest shows a spinner (no more silent freeze). Harvest now emits librarian_ingest events into the run's trace.jsonl (what each ingest wrote/merged); standalone ingest still audits to knowledge/wiki/log.md.
  • Aesthetics — Final ranking, the review gate, and the Usage summary are now rich tables; ingest/harvest output is styled. All interactive prompts already moved to questionary (arrow keys fixed).
