How to run mise

Dev environment is managed by mise (toolchain + .venv + env + tasks); secrets in mise.local.toml (gitignored), no .env.

cp mise.local.toml.example mise.local.toml   # fill keys (only for `live`)
mise trust && mise install                   # python + auto-create .venv
mise run deps                                # package + deps
mise run test
mise run debate -- --topic "…" --tools wiki,openalex,arxiv   # offline, no keys
mise run debate -- --topic "…" --no-anonymize               # B5 ablation knob
mise run live   -- --topic "…"                              # real providers (spends tokens)

Stage A hardening — making ideation usable live 2026-06-06 · 44 tests green

  • Candidate revision applied on revise — a peer that issues a revise contribution now actually patches its own candidate in place (non-empty fields of a CandidateDraft; version bumps) so the revised text is what gets judged that round. A peer may revise only its own candidate (v2 invariant: candidate id == codename) — a guard blocks editing a peer's idea. The orchestrator re-emits a candidate_revised event before judging. (deliberation.py, orchestrator_v2.py, models.py Contribution.revision.)
  • Per-debate retrieval cache — retrieval/cache.py CachedRetrieval wraps the hybrid provider and memoizes (query, k), collapsing the 3 peers' overlapping parallel queries (and repeats across rounds) into a single fan-out via a shared in-flight future. Cuts calls and respects strict public APIs (arXiv 1 req/3 s). Transparent (delegates .providers); scoped per debate via build_retrieval.
  • Live path validated — mise run check pinged all three vendors OK (gpt-5.4 · claude-sonnet-4-6 · gemini-3.5-flash, ~$0). Keys + model ids good; live ideation is ready to run.

First live run — bugs fixed 2026-06-06 · 45 tests green

The first --live attempt reached intake (all 5 questions answered) then crashed in research. Four fixes:

  • Cap crash (blocker) — a peer wanting a 9th tool call hit the cap of 8 and PydanticAI raised UsageLimitExceeded, killing the whole debate. Caps must bound the loop, not abort it. AgentPeer now drives the agent via agent.iter(), catches the limit, and finalizes tool-lessly — a twin agent with no tools coerces the structured output from what was already gathered (trailing un-executed tool-call turns are scrubbed first). Regression test forces the budget to 0 and asserts a brief still comes back.
  • Setup wizard skipped — ideate never called _interactive_setup (only debate did), so seat-model + tool selection was bypassed. Now wired (arrow-key models on --live + tool checklist).
  • Facilitator model surfaced — was hardcoded to the Anthropic seat. Now a config value RC_FACILITATOR_MODEL (mise, vendor fixed to anthropic), default claude-sonnet-4-6, shown in the run header.
  • Deprecation warnings — model prefixes updated to non-deprecated openai-chat: / google:.
