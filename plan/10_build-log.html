How to run mise

Dev environment is managed by mise (toolchain + .venv + env + tasks); secrets in mise.local.toml (gitignored), no .env.

cp mise.local.toml.example mise.local.toml   # fill keys (only for `live`)
mise trust && mise install                   # python + auto-create .venv
mise run deps                                # package + deps
mise run test
mise run debate -- --topic "…" --tools wiki,openalex,arxiv   # offline, no keys
mise run debate -- --topic "…" --no-anonymize               # B5 ablation knob
mise run live   -- --topic "…"                              # real providers (spends tokens)

Notes

  • Offline debate path uses StubPeer (bypasses providers) so the loop runs with zero keys; StubProvider exists for provider-layer parity.
  • Stub peer/retrieval content is placeholder — it exercises the flow + contracts + trace, not real research output.
  • Every baseline is a config of this one path: --seats all-one-vendor = B3; --no-anonymize = B5; verifier mode = B4 (Research Framing).
  • Now a git repo (git init done) — enables the wiki snapshot/commit-hash discipline the eval design relies on.
