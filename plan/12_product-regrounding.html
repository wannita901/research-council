Product Re-grounding — Agentic Council (v2)

2026-06-05 · North-star after the pivot · Supersedes the eval-first framing where they conflict

The goal has shifted: build a working agentic system that actually helps do AI4SE research in the wild — a PoC that keeps working — rather than a controlled study built to satisfy a publication. Same backbone (cross-vendor multi-agent debate, LLM-Wiki, tools, UI); but the peers become autonomous agents, and we drop "deterministic + absolute-minimal + eval-first" as design constraints.

1. What stays (backbone, unchanged)

  • Cross-vendor multi-agent debate — 3 peers, one per vendor (OpenAI · Claude · Gemini). Still the differentiator.
  • LLM-Wiki knowledge layer + librarian (8/9) — long-term memory across debates.
  • Tools / retrieval — wiki · openalex · arxiv · semanticscholar · github, selectable per round.
  • Human-in-the-loop review gate — iterate / amend / conclude / select.
  • Anonymized panel judging (quality control, not just an eval knob).
  • Provider abstraction · mise · trace/observability · FastAPI backend · future UI (11).

2. What changes (the agentic turn)

  • Peers are autonomous agents. In research, each peer runs its own think → call tool → observe loop, deciding which tools to call, what to query, and how many loops to run — bounded by caps.
  • Independent research, for real. Each peer explores differently (its own queries/tools), not the same handout.
  • Rounds re-enter from Phase 1 with memory. A new round re-runs research carrying forward each peer's own prior work, the peers' candidates/critiques/verifier signals, and your comment.
  • Phases 3–5 collapse into Deliberate. Critique + rebut become a real multi-party, multi-turn discussion (agents address each other, ask/answer, defend, concede, revise). Verification stops being a fixed phase — it becomes a grounding tool agents call to settle disputed claims.
  • Caps everywhere to stay safe in the wild (no runaway loops / overspend).
  • Determinism dropped; minimalism relaxed; eval demoted to optional.

3. Execution model v2

   │
   ▼
ROUND r ───────────────────────────────────────────────────────────

        context_in = topic + (r>1 ? own prior brief/candidate
                     + peers' candidates + critiques + verifier signals

  4 JUDGE          → ANONYMIZED panel vote (authorship hidden) → recommendation

   ▼

   │

   └─ conclude / select → DONE
  caps: max_rounds · debate $/token budget

4. The agentic peer (research phase)

peer.research(topic, context, tools, budget):
    scratch = context                       # own + peers' prior + your comment (r>1)
    for step in 1..MAX_ITERS:               # ← loop cap
        plan = think(scratch)               # decide: search? which tool? what query? done?
        if plan.done or budget.spent: break
        obs  = call(plan.tool, plan.query)  # agent-chosen tool + query (any selected tool)
        scratch += obs
    return synthesize_brief(scratch)        # grounded gap + evidence refs
# caps: MAX_ITERS · MAX_TOOL_CALLS · per-agent token/$ budget · hard deadlock stop

Tool-calling is the mechanism (native per-vendor now; MCP an optional backend later). The same loop pattern powers deliberation below.

4b. Deliberation — the group discussion (was phases 3–5)

A shared, all-visible thread where the three peers actually argue, capped and convergence-aware:

state: thread (all see it) · candidates (revisable) · open_questions
loop sub-rounds (≤ MAX_TURNS, within budget):
   for each peer (round-robin; a peer with an open question to it speaks first):
       msg = peer.contribute(thread)      # critique | ask(@peer) | answer | defend | concede | revise
       if msg.kind == revise:  update that peer's candidate
       if msg.needs_grounding: result = verify_tool(claim)  → into thread
   stop when: no open questions AND no new substantive point this sub-round  (converged)
              or MAX_TURNS / budget reached
→ (possibly revised) candidates + full discussion transcript
  • Addressing: messages carry an optional to; an addressed peer answers next.
  • Identity: peers speak under stable codenames (pseudonyms); the codename→vendor mapping is hidden from the agents (shown only to you / in the trace), curbing cross-vendor favoritism. Judging strips authorship entirely (anonymized).
  • Verification = a tool here, not a phase: grounding checks (citation/benchmark/repo exists) on demand; the heavy "run a scaffold/tests" check belongs to the later execution stage.
  • Nondeterministic but bounded by turns + budget; candidates may change during the discussion.

5. Memory model (two tiers)

Within-debate (working)

The run trace + each peer's scratchpad. Carried across rounds so the council builds on itself and on your feedback.

Across-debate (long-term)

The LLM-Wiki — curated, compounding knowledge ingested between debates; peers consult it as a tool.
