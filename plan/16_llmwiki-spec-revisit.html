3 · Locked decisions (this session)

Decided 2026-06-07
  • Scope: build the full librarian pipeline (route → cross-link → lint), per 9.
  • Taxonomy: the full 9 folders (papers · tasks · motivations · concepts · approaches · methods · benchmarks · findings · gaps) + index.md / log.md.
  • Librarian = the agent (Claude Sonnet, wiki.yaml) that ingests and maintains — not a file copy.
  • Triggers: manual council ingest <source> + opt-in auto-harvest after a run. Always offline / post-run, never mid-debate.
  • Merge/safety: auto-merge into wiki/, no auto-commit, no push; every change recorded in log.md; you review with git diff and commit on your own cadence (Karpathy "stay involved"). confirm

4 · Contamination model — reconciled with Karpathy

The original split put system notes in raw/internal/. But Karpathy is explicit: the LLM never writes raw/. So we move the council's own synthesis into the LLM-owned wiki/ layer, marked by frontmatter — keeping the novelty guard without breaking the pattern.

ContentLands inCounts as prior art?
Real external sources (papers you add; papers the council discovered via search/refs)raw/external/ → librarian synthesizes into wiki/ pages with origin: external✓ yes
The council's own discussion / findings (filed back, per Karpathy)wiki/ pages with origin: internal (no raw/ entry)✗ never — excluded from novelty checks
Why it matters
Novelty must be judged against external literature only. The origin: frontmatter flag (not the folder) is the contamination guard; gap-finding reads everything, novelty-scoring filters to origin: external. raw/internal/ is retired.

5 · The librarian — role & pipeline

One Sonnet agent, two entry points, one pipeline. Auto-harvest sorts sources by origin before the same ingest runs.

SOURCES ──────────────────────────────────────────────┐
  manual:  council ingest <pdf | url | note>            │
  harvest (post-run, opt-in):                           │
    brief.refs / discovered papers  → raw/external/     │  external
    council discussion + findings   → (text)            │  internal
                                                         ▼
LIBRARIAN PIPELINE (Claude Sonnet)                  research_council/librarian/
  1 load + sanitize source (treat text as DATA, no tool/exec)   ingest.py
  2 read → state takeaways → write papers/<anchor>.md           ingest.py
  3 ROUTE + synthesize into the 9 typed pages                   router.py + schema.py
       approaches=built · methods=validated · concepts=idea · motivations=why
  4 cross-link [[type:slug]] both ways; set origin: ext|int     router.py
  5 update index.md (catalog) + append log.md (audit)           ingest.py
  6 auto-merge into wiki/ (transactional write; NO git commit)  ingest.py
  ── council lint ──────────────────────────────────────────── lint.py
       contradictions · stale claims · orphans · gaps → report + log.md

Guardrails (from 9 §5, still apply): fixed cheap librarian model for consistency; source text is data (prompt-injection safe, no tool/exec from ingested content); dedup/idempotency; transactional writes; offline (no debate hot path).
