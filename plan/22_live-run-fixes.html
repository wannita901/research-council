2 · Incremental iteration (Q3) — improve, don't rebuild

Continuation is driven by the artifacts already on disk, so it works for both the conductor's redo and a plain project approve re-run.

  • Stage B — load_prior_experiments(out_dir) reads each experiment/<rq>/ (prior experiment.py + reviews + run log) and seeds that RQ's coder on attempt 1, so it revises the existing script with the prior feedback rather than drafting fresh.
  • Stage C — load_prior_paper(out_dir) reloads the prior draft and the revision loop continues from it; a redo no longer re-asks the venue (reuses the project's choice).
  • Stage A added 2026-06-10 — a redo ideation now seeds the new debate with the previous proposal (+ an optional human note) via run_ideation(prior_context=…), so the council improves that proposal rather than starting from a blank slate.

council run --resume <id> re-enters the conversational gate loop on an existing project (skips new ideation) — for picking up after a stop / Ctrl-C without dropping to the per-stage project approve. It continues from the project's current gate (must be awaiting_approval). --from <stage> added 2026-06-11 rewinds to an earlier stage and continues from its existing artifacts: lifecycle.rewind_to sets the target back to awaiting_approval (keeping its on-disk artifacts so the engine improves rather than rebuilds) and resets later stages to pending; earlier stages stay approved (their artifacts are the input). Guards: the target must have run, and its prior stage must be approved.

3 · Stage-B approval (Q5)

  • Bug: the reviewer prompt truncated the code to 3000 chars, so the council (correctly) flagged "truncated / syntactically invalid" and blocked it. Now it gets the full script, told it's the complete code that already ran.
  • Mismatch: the coder is told "toy/synthetic is fine (smallest runnable step)", but reviewers demanded the full real benchmark and blocked on "it's synthetic". Realigned the reviewer's bar: a labelled toy/proxy is expected at Stage B; block only on genuine correctness/soundness errors.

4 · Stage-C build (Q6)

  • Path bug: _compile set cwd to the paper dir but passed the full relative path, so latexmk looked for paper/paper/paper.tex. Fixed (resolve to absolute + bare filename). Verified: relative-path builds now compile.
  • Build-fix feedback: on a genuine compile failure the council's LatexFixer agent now gets the .tex + build.log and recompiles (bounded by latex_fix_attempts) — the fail log is the feedback. The mechanical pass (escaping, doc-class fallback) still runs first.
